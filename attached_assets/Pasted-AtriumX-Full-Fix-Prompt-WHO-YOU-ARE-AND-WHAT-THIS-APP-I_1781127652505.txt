AtriumX — Full Fix Prompt
WHO YOU ARE AND WHAT THIS APP IS
AtriumX is a mobile-first React/TypeScript student marketplace. Students at university
residences buy, sell, and offer services to each other. Businesses advertise to
students. An admin moderates listings. Backend is Supabase. Deployed on Cloudflare
Pages using HashRouter.

FIX T01 — supabaseClient.ts must not crash at module load
Why this matters: If this file throws synchronously, every file that imports it
also fails. AppContext, dataService, and every page collapse. The result is a blank
screen that no error boundary can catch.
What to do: Replace the entire file with this exact content:
typescriptimport { createClient } from '@supabase/supabase-js';

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL as string;
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY as string;

export const supabase = (supabaseUrl && supabaseAnonKey)
  ? createClient(supabaseUrl, supabaseAnonKey)
  : createClient(
      'https://placeholder.supabase.co',
      'placeholder-key'
    );
Side effect check: Every file that imports supabase will now receive a valid
client object instead of an undefined or thrown error. The placeholder client will
fail on actual requests (returning network errors) but will not crash the module
graph. This is safe.
